================================================================================

four-channel ecosystem: the book, an AI tutor (TutorClaw), an AI building
partner (Agent Factory Skillpack), and a growing family of specialized
derivative books.

Companies. For engineers, domain experts, and enterprise leaders building
the workforce of the Agent era.

Canonical = the authoritative source. The one master version everything
else is built from.

================================================================================
CORE IDEA
================================================================================

Digital FTEs (Digital Workers) = reliable AI agents designed to perform
structured knowledge work continuously inside real organizational environments.

A Digital FTE is not just a model with a prompt. It is a SYSTEM combining:
  1. Domain Expertise — the "knowledge engine" guiding reasoning
  2. Structured Specifications — clear definitions of what agents must do
  3. Engineering Architecture — infrastructure for reliability and scalability
  4. Human Oversight — feedback loops for accountability and governance

Together = AI-Native Company

Terminology: Digital FTE = Digital Worker = AI Worker (interchangeable)

THIS BOOK IS INFRASTRUCTURE: THREE MODES OF DELIVERY
================================================================================

  Mode 1: READ — Traditional human reading. Chapters, frameworks, exercises.
  Mode 2: TUTOR — TutorClaw. 24/7 AI tutor with persistent memory across
           WhatsApp, Telegram, and web. Teaches from the same governance
           principles and frameworks.
  Mode 3: BUILD — Agent Factory Skillpack. AI building partner running in
           Claude Code and OpenCode. Guides spec writing, SKILL.md
           structuring, escalation protocols, MCP connector configuration.

Same knowledge base powers all three modes. Updates propagate to all three
simultaneously. This is the 10-80-10 pattern applied to education.
